# Introduction to Image Analysis (1MD110)

Coursework for **Introduction to Image Analysis (1MD110)**, Uppsala University — M.Sc. programme in Image Analysis and Machine Learning (Autumn 2025).

Classical image analysis: pixel-level operations, filtering, edge and feature detection, segmentation, morphological operations, and basic image classification. Labs are implemented in Python (NumPy, SciPy, scikit-image, OpenCV, matplotlib).

## Contents

Each lab lives in its own folder with the problem statement, code, and a short write-up of results.

- `lab1/` — image representation, histograms, point operations
- `lab2/` — spatial filtering, convolution, noise reduction
- `lab3/` — edge detection and feature extraction
- `lab4/` — segmentation and morphological operations
- `lab5/` — image classification

*(Folders reflect the labs that have been completed — some are still in progress.)*
